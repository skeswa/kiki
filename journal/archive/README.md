# Earlier plans and implementation records

they remain useful history. Preserve the original context and link to the
current successor. Archived work is not current operating guidance.

the [build sequence](../../docs/reference/book/15-build-sequencing.md), and
deferred work lives in the [roadmap](../../docs/reference/book/16-roadmap.md).
